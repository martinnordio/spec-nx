Author Q&A

Why one spec for twelve migration items instead of one spec each?
The author wanted one review and one pull request; each item is one Step and one commit, so the history still shows them separately (spec decision D1).
Why does a company layer exist instead of company files in spec-nx?
spec-nx is open source and must name no company (S15). The layer keeps a company's stack, rules, Looks and permissions private, next to spec-nx, without a fork (S7).
Can VS Code Copilot block git push like Claude Code?
No. Its terminal setting can only require approval, so the kit's prompts keep the rule "never commit or push" for every agent.
