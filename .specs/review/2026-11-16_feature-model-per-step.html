The Right Model and Cost for Each Step — semantic diff

Branch feature/model-per-stepBase ec52844Head bbc2e72 Target mainDate 2026-11-16 Commits 14Files 24 · +1937 / −18 Written by REVIEW: · Claude Opus 5.5

Summary

  • A new setup question Q7 lets a project run a model per Step (reasoning / standard / light), one fixed model, or none; a developer can override it.
  • Every stage checks its model first and runs as a sub-agent on it; the plan picks the cheapest tier per Step; IMPLEMENT: asks once and runs the Steps on their models.
  • With a cost block, every Stage log row and Done line gets its tokens and cost (credits, CHF, % of the plan) from two new scripts; CLOSE: adds a cost summary and .specs/costs.md lists all specs.
  • COSTS.md explains the method and says that all costs are estimates and may be wrong; the README shows the feature at the very top; docs/configuration.md explains every setting.
  • Without models and cost, kits and specs behave exactly as before.

Recommendation: Approve with follow-ups — nothing Blocking; transcript discovery per workspace and an end-to-end GENERATE KIT run (Should-fix) are deferred.

Author Q&A

Why are VS Code Copilot numbers estimates?
Its chat transcript has every turn but no token counts. The script counts characters ÷ 4, treats the previous request's context as cached and resets at the context cap (D11); COSTS.md lists the limits. Claude Code logs real usage, so those numbers are measured.
Is the cost what we pay?
No — it is the value of the GitHub AI credits used at Copilot's per-token rates. Within the plan's monthly credits nothing extra is paid. COSTS.md and every number say "estimate".
Does an existing project start tracking cost after --update?
No. GENERATE KIT --update never adds the cost block; only the first GENERATE KIT writes it. Q7 is asked once on --update because it is a new question.
Why does the bash script need python3?
Reading JSON lines and doing the arithmetic in plain bash would need jq and bc and still differ from PowerShell; python3 gives the same numbers as the PowerShell script.
