## The workflow

One feature = one spec = one branch `feature/<name>` = one pull request. Every commit message
carries the reference of the spec's issue (`#<n>`) or backlog item (`AB#<id>`) —
`guidelines/commits.md`.

| # | Stage | Command | Result |
|---|-------|---------|--------|
| 1 | requirements | `REQUIREMENTS: <name> — <what you want>` | Part 1 of `.specs/features/<date>_<name>_spec.md`; answer its open questions with `REQUIREMENTS: <spec file> — <answers>` |
| 2 | plan | `PLAN: <spec file>` | Part 2: Steps, decisions, Definition of Done |
| 3 | implementation | `IMPLEMENT: <spec file>` — once per Step, commit after each | Code + the Step marked done |
| 4 | documentation | `DOCS: <spec file>` | The documents the change affects |
| 5 | review | `REVIEW: <spec file>`, `CODE REVIEW: <spec file>` | Semantic diff for the pull request; findings in the Review Log |
| 6 | implementation | `CLOSE: <spec file>` | Spec moved to `.specs/features/done/` |
| 7 | pr | `PR: <spec file>` | Pull request (and issue) updated with the spec summary |

## Now and then

| Command | Stage | Does |
|---------|-------|------|
| `CREATE ISSUE: <spec file> [parent <n>]` | requirements | Creates the issue / backlog item of the spec (optionally under a parent); offered when the requirements are finished |
| `UPDATE ISSUE: <spec file>` | requirements | Summary of the spec into its issue / backlog item |
| `GUIDELINES: <language>` | guidelines | Writes or updates `.specs/guidelines/<language>.md` |
| `ARCHITECTURE`, `ADR: <title>` | documentation | Architecture document, decision records |
| `IMPROVE: <scope>` | improvement | A clean-up spec that never changes behaviour |
| `SETUP TOOLING: <scope>`, `SETUP MACHINE` | setup | Specs for tooling and for a developer's computer |
| `LOOK: <app>`, `UI CATALOG` | ui | A look spec; the UI catalog |

## Settings

- `.specs/spec-nx.json` — the team's answers (committed).
- `.specs/spec-nx.local.json` — your answers, e.g. your shell (not committed).
- Update the kit: `git submodule update --remote .spec-nx`, then load
  `.spec-nx/generator/prompt.md` and run `GENERATE KIT --update`.
